# A股每日决策简报（中国版）

一个**单文件 HTML** 的每日简报看板。每天自动读一次数据，更新到 GitHub 仓库，GitHub Pages 直接可看；文件下载到本机双击也能打开（显示最近一次内置快照）。

## 它和原版 daily_stock_analysis 有什么不一样

| | 原版 | 这一版 |
|---|---|---|
| 主要形态 | 白底长文推送 + 深色开发者工作台 | 一屏结论 + 卡片化简报 |
| 颜色 | emoji 圆点（绿买红卖） | **红涨绿跌**，按 A 股习惯 |
| 阅读量 | 大段文字，手机要滑很久 | 每卡一个结论，最多 3 行 |
| 措辞 | 含买入/卖出/目标价 | 只给**信号 / 观察 / 风险**与纪律提示 |
| 主题 | 固定 | 深色 + **白底（券商风）**一键切换 |
| 部署 | AI Key + 多数据源 + 推送服务 | 零依赖，GitHub Actions 每天跑一次 |
| 离线 | 否 | **是**，数据内置在 HTML 里 |

## 每天怎么更新

- **时间**：北京时间 **15:30**（收盘后），由 `.github/workflows/daily.yml` 定时触发，一天一次。
- **动作**：`update_data.py` 抓一次数据 → 写 `data/daily.json` → 把最新快照注入 `index.html` → 自动 commit & push。
- **手动**：GitHub 仓库 → `Actions` → `每日更新 A 股决策简报` → `Run workflow`，随时可点。
- **页面读取**：部署在 Pages 上时优先读 `data/daily.json`（当天最新）；本地 `file://` 双击时读不到就自动用内置快照，所以断网也能看。

## 数据从哪来（不编造）

1. `wangjun20251978/ETF-ROTATION-PRO` 的 `docs/index.html`：48 只 ETF 三因子实测表（M 动量 / V 相对低位 / F 资金流 / 综合分 / 风控 / 信号天数 / 最优持股）。
2. 同仓库 `docs/history.json`：信号归档（时间、持仓、通过数、大盘状态、总仓位）。
3. 东方财富公开接口：上证 / 深证 / 创业板 / 科创50 四大指数。**抓不到就沿用上次或显示「数据暂缺」，绝不填假数字。**

「池内温度」为自定义口径：上涨占比 × 60 + 风控通过率 × 40，满分 100，仅用于一屏感知冷热。

## 本地怎么用

- 直接双击 `index.html`，无需安装任何东西、无需联网、无需 API Key。
- 想刷新数据：在仓库目录执行 `python update_data.py`（需联网），会重新抓一次并改写页面。
- 右上角「☀ 白底」可切换成同花顺 / 东方财富那种白底风格；「复制今日简报」生成纯文本，可直接粘到微信或企业微信群。

## 目录

```
index.html                     单文件看板（含内置数据快照）
data/daily.json                每日数据
update_data.py                 抓数 + 注入脚本
.github/workflows/daily.yml    每日定时任务
```

## 合规

本简报是公开数据的整理与界面演示，评分、信号、状态均为历史快照记录，**不构成任何投资建议，不可作为买卖依据**。页面不含基金/个股推荐代码组合，不提供买卖指令。市场有风险，决策请自行判断。
